## Sobre mim

Sou desenvolvedor Full Stack com experiência na criação de sites institucionais, e-commerces, dashboards, plugins WordPress, temas personalizados, APIs e integrações.

Tenho atuado principalmente com projetos envolvendo WordPress, WooCommerce, Next.js, React, TypeScript, PHP, NestJS, bancos de dados relacionais e integrações com CMSs como Strapi.

Gosto de desenvolver soluções bem estruturadas, com foco em performance, organização de código, experiência do usuário e facilidade de manutenção.
